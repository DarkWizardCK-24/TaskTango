# ✅ TaskTango

TaskTango is a sleek and intuitive Todo web application built with React and JavaScript, designed to streamline your task management. With a modern, responsive UI, it allows you to effortlessly create, update, and track your tasks. Hosted on Vercel for fast, scalable performance, TaskTango keeps you organized and productive with style! 🚀

# ✨ Features

1. 📋 Task Management: Create, update, delete, and mark tasks as complete.
2. ⚛️ React-Powered: Dynamic and component-based UI for a smooth experience.
3. 📱 Responsive Design: Seamless functionality across desktops, tablets, and mobiles.
4. ☁️ Vercel Hosting: Lightning-fast deployment with global scalability.
5. 🛠️ JavaScript Functions: Lightweight and efficient task-handling logic.



# 🛠️ Tech Stack

1. React: Modern JavaScript framework for dynamic, component-based UIs.
2. JavaScript: Core logic for task management and functionality.
3. Tailwind CSS: Utility-first CSS for responsive and stylish design.
4. Vercel: Fast, scalable hosting with seamless deployments.
